Este projeto transforma o texto de ~500 mil avaliações da Amazon em análise consultável.

A partir do texto e da nota, identifica os motivos de insatisfação do cliente e o que leva um produto a ser bem ou mal avaliado, classificando cada avaliação por aspecto (qualidade, preço, entrega, embalagem).

Inclui também consulta em linguagem natural sobre as avaliações, usando busca semântica para responder perguntas como "o que dizem sobre o produto X".
